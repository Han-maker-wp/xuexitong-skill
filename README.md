# xuexitong-skill — AI Agent 的学习通(超星)全能技能包

一个遵循 [Agent Skills 开放规范](https://agentskills.io) 的技能包(SKILL.md),让 AI Agent 熟练操作**网页版学习通**(i.chaoxing.com):

- 📋 **作业仪表盘**:遍历全部课程,汇总未完成作业与截止时间
- ✍️ **作业辅助作答**:AI 逐题作答单选/多选/判断/填空/简答/计算,**只暂存、绝不自动提交**,输出"答案审核单"由你审核后手动提交
- 📥 **课件资料下载**:一键拿到官网不给下载按钮的 PPT/PDF 直链
- 📊 **信息查询**:通知、成绩、章节进度、考试时间(只读)
- 🟡 **可选灰色功能**:视频任务点挂机、签到检测提醒(默认关闭,需你当场明确指令)

> **设计哲学:AI 只做辅助,提交权永远在人。**作业答案一律先暂存生成审核单,你看过、改过、自己点提交。

## 安装

技能本体在 [`skills/xuexitong/`](skills/xuexitong/),把**这个目录**拷进你的 Agent 客户端技能目录即可:

| 客户端 | 技能目录(全局) |
|---|---|
| ZCode | `~/.agents/skills/` |
| Claude Code | `~/.claude/skills/` |
| Codex CLI | `~/.agents/skills/`(也读 `~/.codex/`;**拷贝**,不要软链接,有已知 bug) |
| Trae | `~/.trae/skills/`(Windows: `%userprofile%\.trae\skills`;也兼容 `.agents/skills/`) |
| CodeBuddy(腾讯) | 项目内 `.codebuddy/skills/` |
| Hermes Agent | `~/.hermes/skills/` |
| 其他遵循 Agent Skills 规范的客户端 | 找到其 skills 目录整目录拷入 |

```bash
# 通用安装(以 ZCode 为例)
git clone https://github.com/Han-maker-wp/xuexitong-skill.git
mkdir -p ~/.agents/skills
cp -r xuexitong-skill/skills/xuexitong ~/.agents/skills/
```

**插件市场方式**(Claude Code / ZCode):

```
/plugin marketplace add Han-maker-wp/xuexitong-skill
/plugin install xuexitong-skill
```

> 前置条件:客户端里要有一个能操作浏览器的工具(browser-use / chrome-devtools MCP / Playwright MCP 任一),动作映射见 [`references/browser-adapters.md`](skills/xuexitong/references/browser-adapters.md)。登录用你自己的浏览器会话,本技能**不做协议逆向、不碰密码加密**。

```text
看看我学习通有什么作业要交

```

## 工作原理

1. **复用真实登录态**:在你已登录的浏览器里操作,不逆向协议、不模拟加密登录——免验证码、不会因前端改版失效。
2. **跨域 iframe 导航**:学习通页面全是跨域 iframe,技能内置了实测校准的导航地图(课程入口、作业/资料/章节/活动各标签的 iframe 结构)。
3. **脚本化提取/回填**:`scripts/` 提供 4 个实战校准的页面脚本(课程清单/作业列表/题目提取/答案回填),选项按字母与显示文本匹配(平台会把 data 属性随机化),UEditor 富文本走 `setContent+sync`。
4. **22 条踩坑速查**:加密字体、公式图片、频率限制、渲染假死等实测坑全记录在 [`references/pitfalls.md`](skills/xuexitong/references/pitfalls.md)。

## 免责声明

- 本项目**仅供学习交流与技术研究所用**,与超星官方无任何关联。
- 使用前请了解并遵守你所在学校的规定与《学习通用户协议》。作业代答可能违反学术诚信要求;视频挂机、代签到属违反平台规则的行为,有**进度清零、封号、学术处分**风险,超星曾对自动化项目发出律师函。相关灰色功能默认关闭,启用后的后果由使用者自行承担。
- 本项目不提供、不内置、不爬取任何题库;AI 生成的答案可能出错——**这也是默认不自动提交、必须人工审核的原因**。
- 请勿将本技能用于有监考的正式考试。

## 已知限制

- 学习通页面改版可能导致选择器失效(技能内已附现场探测与自纠方法,欢迎提 Issue/PR 回报新结构)。
- 资料下载的文件落盘依赖浏览器工具;部分教师会关闭文件下载权限(`download` 字段为 null),此时无法下载。
- 数学公式的题面/选项是图片渲染,需要多模态读题;加密字体(`font-cxsecret`)同理。
