# 答案源(可选,默认关闭;用户自备)

> 🔴 **红线不变**:本 skill **不内置、不爬取、不分发任何题库**。本模块只提供"答案源"的接入框架——答案接口由**用户自行搭建或自行选择可信第三方**并自行配置,搜题服务的合法性与合规风险由用户自担。不配置 = 纯 AI 推理模式(默认)。
> 设计参考了 Samueli924/chaoxing(GPL-3.0)的答案源架构思路,本项目独立实现、未复制其代码。

## 答案源优先级(三层,高→低)

1. **用户答案文件**——用户自己整理的答案(最可信,标注 `用户答案`);
2. **用户自配 HTTP 答案接口**——自建服务或用户选定的第三方接口(标注 `接口命中`);
3. **AI 推理**——skill 内置能力(标注 `AI 推理`)。

所有来源都**只写进答案审核单供人工复核**,提交永远由用户决定(全局红线)。

## 1. 用户答案文件

把你自己整理的答案存成 JSON(工作目录,如 `my-answers.json`):

```json
{
  "条件概率": "B",
  "全概率公式": "对",
  "大数定律": ["A", "C"],
  "中心极限定理的表达式": "∫f(x)dx"
}
```

- key 是**题干子串**(包含即可命中,建议取题干中稳定的关键词,别带题号和分值);
- value:单选/判断填字符串(字母或"对/错"),多选填字母数组,填空/简答填文本;
- 命中即采用,置信度标"高(用户答案)",不再查接口。

## 2. HTTP 答案接口(自建/自选)

配置文件 `answer-source.json`(工作目录):

```json
{
  "endpoint": "https://你的接口地址/search",
  "token": "可选,作为 Bearer 发送",
  "answersFile": "my-answers.json",
  "cacheFile": "answer-cache.json",
  "timeoutMs": 8000
}
```

接口约定(兼容 [tikuAdapter](https://github.com/DokiDoki1103/tikuAdapter) 项目格式,便于直接对接其生态):

- 请求:`POST endpoint`,body `{"question": "题干文本", "options": ["选项A文本","选项B文本",...], "type": 0}`
  type:0 单选 / 1 多选 / 2 填空 / 3 判断 / 4 其他;
- 响应:接受任一形状——`{"answer": {"bestAnswer": ["B"]}}`(tikuAdapter)或 `{"answer": "B"}` 或纯文本;
- 建议接口带鉴权与限速;skill 侧每次查询间隔 ≥1 秒。

## 3. 查询入口

先跑题目提取(`extract_questions.js`)拿到 questions JSON,然后(Node 侧,不是页面上下文):

```bash
node scripts/answer_source.js --questions questions.json [--config answer-source.json]
```

输出 `answer-source-result.json`:`{results:[{index, source, answer, note}], coverage:"N/M"}`,把命中结果合并进作答流程:命中项直接作为候选答案(理由注明来源),未命中项走 AI 推理。

## 4. 内置的质量防线(来自社区实测经验,已固化在脚本里)

- **题面清洗**:去题号前缀、去"(2.5分)"分值后缀、合并空白——提高接口与缓存的命中率;
- **本地缓存** `answer-cache.json`:题干→答案,重做/重查不重复请求;
- **题型-答案一致性校验**(不符即弃用该来源,降级到下一层):
  - 单选题:答案含强分隔符(换行/`|`/`#`/顿号)视为无效;答案长得像判断题(对/错/true)视为无效;
  - 判断题:同义词归一(`对/正确/√/是/true/1 → 对`;`错/错误/×/否/false/0 → 错`),归一不了的视为无效;
  - 多选题:从答案文本里提取 A-G 字母集合;
  - 填空/简答:非空即可(内容质量靠审核单人工把关)。

## 5. 覆盖率统计

审核单顶部标注 `答案源命中 N/M`(N=非 AI 推理的题数)。命中率高说明这科题库质量好,AI 推理的题建议用户重点复核——这是比"置信度"更硬的信号。

## 6. 明确不做的

- 不内置任何题库提供商的地址、token、账号;
- 不批量爬取题库、不做题库镜像;
- 不把用户题目数据发送到用户配置之外的任何地址;
- 接口返回的答案也**只进审核单**,不自动提交。
