# 视频任务点挂机【灰色功能 · 默认关闭】(2026-09 真机校准)

> ⚠️ **先读风险**:自动挂机违反平台使用规则。教师后台能看到学习过程数据(倍速、切屏次数、学习时长),平台可检测异常并清空课程进度;部分学校认定为学术不端。
> **只有用户当场明确说"挂机/刷视频/完成任务点"才执行;执行前用一句话再次确认。**默认回应:可以做进度查询(见 info.md),但建议自己看。

## 硬约束(不可违反)

- 只在**真实浏览器**里正常播放,默认 **1 倍速**,不开倍速、不改播放器参数。
- **不伪造 enc、不发任何协议/接口请求、不篡改进度上报**——进度必须由真实播放产生。
- 保持标签页前台(后台标签会被平台暂停);不并行刷多门课。
- 遇到"需要人脸/验证码"的关卡立即停下交给用户。

## 定位未完成任务点(真机验证的结构)

1. 课程页"章节"标签 → `#frame_content-zj`(mooc2-ans/mycourse/studentcourse)。正文首行 `已完成任务点: X/Y`,每节行有任务点计数(橙色圆点数字)。
2. 节行结构:`li` 内 `div.chapter_item`,其 **id 就是 `cur<knowledgeid>`**(如 `cur1216527069`)。用 frameLocator 的 `li.filter({hasText:'节名'})` 定位,`getAttribute('id')` 取 knowledgeid。
3. 打开该节卡面(真机验证可用):
   `https://mooc1-1.chaoxing.com/knowledge/cards?courseid=<>&clazzid=<>&knowledgeid=<>&cpi=<>&ut=s&enc=<课程页URL里的enc>&mooc2=1`
   ——enc 用课程主页面 URL 里的那个,不能少。
4. 卡面页里视频是 `iframe.src` 含 `ananas/modules/video` 的元素;测验卡是 work/doHomeWorkNew 类 iframe。

## 挂机流程

1. 逐节找视频任务点,进卡面页点播放;
2. 轮询播放器 video 元素 `currentTime / duration`(每 30 秒);
3. 处理弹窗:"继续任务"横幅→点继续;插入题(单选/判断,一般不计分)→选常识项提交;会员倍速提示→忽略保持原速;
4. **遇到已关闭/锁定的任务点**(教师设置了完成顺序):默认跳过并汇报;用户要求重试时最多重试 3 次(Samueli924 项目的 notopen 经验:无限重试无意义),仍失败就停下汇报;
5. 播完(currentTime ≥ duration 98%)→ 下一任务点;
6. 收尾:刷新章节页核对 `已完成任务点` 真实增长;汇报完成清单与总耗时,提醒过程数据教师可见。
