# 签到【灰色功能 · 默认关闭】(v2,吸收 cxOrz/chaoxing-signin 设计)

> ⚠️ **先读边界**:代签到违反校规与平台规则,有进度清零/处分风险(超星曾对自动化签到项目发律师函)。**默认行为 = 检测 + 提醒**。
> **硬线(不可逾越)**:agent 绝不自行生成或挑选签到证据——不自己找照片、不自己选坐标、不猜 enc/签到码。所有代操作都必须:**用户本人提供证据 + 当场明确指令 + 每次单独确认**。

## 一、检测与监控(合规,真机验证通过)

### 单次检测
1. 进课程页(见 login-and-nav.md),**默认第一个 iframe 就是活动列表**:`#frame_content-hd`(mobilelearn.chaoxing.com/page/active/stuActiveList?courseid=..&clazzid=..)。
2. frameLocator 读 `#frame_content-hd`:条目是 `[activeid]` 元素(`activeRowClick(this)`),文本结构实测:
   `<活动名> 结束时间：<MM-DD HH:mm>`;页面分区 `进行中（N） 已结束（M）`。
3. "进行中"计数非 0 → 立即、显著提醒用户(活动名 + 剩余时间 + 类型)。

### 跨课程监控模式(用户要求"帮我盯着"时)
对每门课循环(路线已验证):goto interaction → 页内跳转课程 → 读 `#frame_content-hd` → 收集 `进行中` 活动:

```js
// Node 侧循环示意(每轮):
// 1. goto interaction?s=…
// 2. 对每门课:evalJs location.href=stucoursemiddle 链接 → 等 4s
// 3. frameLocator('#frame_content-hd') 读 body 文本,正则抓"进行中（\d+）"
//    与活动条目 [activeid] 的 innerText
// 4. 发现新的进行中活动 → 提醒用户;无 → 等下一轮
```

**轮询纪律**(吸收 cxOrz 监听模式经验):
- 只关注**2 小时内**开始的活动,更早的视为陈旧;
- 同时出现多个进行中活动时,**优先最新一个**,不要每个都操作;
- 轮询间隔 1~2 分钟,单轮扫描全课程约 30~60 秒(课多时只扫本学期有课的);
- 每轮结果记入会话,只在新活动出现时打扰用户。

### 提醒渠道
- Agent 对话内提醒是默认渠道;
- 若客户端支持定时任务(如 ZCode 自动化),可创建"每 15~30 分钟查一次签到"的定时提醒;
- 需要推送到手机的用户可自行在轮询脚本后接 pushplus/邮件 webhook(自备 token,skill 不内置)。

## 二、代操作边界(逐类型;全部需要用户当场指令)

通用流程:从活动列表点击条目进活动详情页(mobilelearn 签到页;若 locator 点击超时,按 browser-adapters 降级坐标点击)。**每次操作前截图留底,操作后截图确认成功标志**(如"签到成功"提示或状态变化)。

| 类型 | 用户须提供 | agent 做什么 | 风险注记 |
|---|---|---|---|
| 普通签到 | 一句"帮我签" | 进活动页点签到按钮 | 低 |
| 手势签到 | 手势图案描述(如"Z 字""左上→右下→右上") | 在九宫格按描述真实滑动(轨迹分 3~5 段拖动) | 图案错会失败,可重试 |
| 签到码 | 4 位数字码 | 填码提交 | 不猜码、不穷举 |
| 二维码 | **enc 值**(教师屏幕二维码里包含;用户自行从照片提取) | 在活动页提交带 enc 的签到 | **旋转二维码每 ~10 秒换 enc**,人工转述基本来不及——旋转码请以现场扫码为主;静态二维码(投影不变)可行 |
| 拍照签到 | **用户本人**的照片文件 | 按超星云盘机制:照片上传云盘根目录(命名 0.jpg/0.png)→ 活动页引用提交 | agent 不自选、不生成、不美化照片;只做上传与点击 |
| 位置签到 | 坐标 + 详细地址(用户从百度拾取坐标系统 coordsys.baidu.com 自取) | 填入经纬度与地址后提交 | 坐标由用户提供,agent 不自选;教师端可见提交的位置与地址 |

**拒绝场景(无例外)**:用户不给证据只说"帮我签"(拍照/位置/二维码);要求 agent 自己想办法伪造;有监考考试相关的任何操作。

## 三、失败与异常处理

- **活动已结束**:提交报错/无按钮 → 如实汇报,不重试不绕过;
- **已签到过**:页面显示已签状态 → 汇报即可;
- **需要现场验证的提示**(如教师开启拍照审查):停止代操作,交还用户;
- **enc 提交失败**:旋转码已过期(>10s),告知用户此路不通的原因;
- 每次代操作的结果(成功/失败截图)写进会话汇报。
